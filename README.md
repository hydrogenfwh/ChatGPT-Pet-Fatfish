# fatfish · ChatGPT Pet

蓝发、蓝眼睛和蓝白女仆装的小伙伴 **fatfish**，为 ChatGPT Work 模式的 Pets 制作。

![fatfish 动作预览](fatfish-preview.gif)

## 使用方法

1. 打开支持 Pets 的 ChatGPT Work 环境，启用 **Pets** 插件。
2. 下载本仓库的 [`fatfish-spritesheet.png`](fatfish-spritesheet.png)：打开文件页面后选择下载，或使用 Git 克隆本仓库。
3. 在新对话中附上这张精灵图，并向 Pets 插件发送：

   > 使用这张精灵图创建一个名为 fatfish 的宠物，验证后选中它。

4. 按插件提示完成创建。成功后，fatfish 会成为当前选中的宠物；也可以之后通过 Pets 插件切换宠物。

> 本仓库提供素材，不是浏览器扩展或可执行程序。克隆仓库本身不会自动安装宠物；Pets 的可用性和界面可能因账号或工作区而异。

## 素材

- [`fatfish-spritesheet.png`](fatfish-spritesheet.png)：透明背景的 v2 精灵图，1536 × 2288 像素，8 列 × 11 行，每格 192 × 208 像素。
- [`fatfish-preview.gif`](fatfish-preview.gif)：九组动作的循环预览。
- [`fatfish.png`](fatfish.png)：放大的静态预览。

精灵图包含待机、左右移动、挥手、跳跃、失落、等待、工作、检查九种状态，以及 16 个视线方向。该文件通过了 Pets 的尺寸、透明背景和帧数检查；部分斜向视线较细微。
